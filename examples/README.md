# 最初の1本の候補

どれも **10〜20秒**、**シーン1から作る**前提です。素材をチャットに渡し、brief を決めてから着手します。

## 0. 実証サンプル（作成済み）
`projects/_sample-assets-test/` — 画像1枚＋効果音1つを id で読み込む 3 秒の Remotion 動画。新しい素材の読み込み方の見本です。

## 1. キネティック短歌（HyperFrames）
短歌を五・七・五・七・七の句ごとに文字が動いて現れる映像。文字組みと間の練習に向きます。
- 素材：フォント（`assets/fonts/`）、任意で BGM

## 2. 曲同期リリック（HyperFrames）
`assets/audio/bgm/` の曲の BPM に合わせ、歌詞が拍で切り替わる映像。CONFIG の BPM で全体のテンポを制御します。
- 素材：BGM、歌詞テキスト

## 3. データ動画（Remotion）
数値がカウントアップし、棒グラフが伸びる映像。数字は props に分離し、差し替えで別バージョンを作れるようにします。
- 素材：数値データ（表や箇条書きでチャットに渡せば可）
