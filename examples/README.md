# 最初の1本の候補

どれも **10〜20秒**、**シーン1から作る**前提です。brief を書いてから着手してください。

## 1. キネティック短歌（HyperFrames / `motion-graphics`）
短歌を五・七・五・七・七の句ごとに文字が動いて現れる映像。文字組みと間の取り方を練習できます。

## 2. 曲同期タイトル／リリック（HyperFrames / `music-to-video`）
`assets/audio/` に置いた曲の BPM に合わせて、タイトルや歌詞が拍で切り替わる映像。CONFIG の BPM で全体のテンポを制御します。

## 3. 数字が動くデータ動画（Remotion）
数値がカウントアップし、棒グラフや円グラフが伸びるデータ映像。数字は props に分離し、差し替えで別バージョンを作れるようにします。
