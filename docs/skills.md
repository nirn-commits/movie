# 使えるスキル集

`bash scripts/setup.sh` で入る公式スキルの早見表です。

## HyperFrames 公式（全28個のうち主要なもの）

### 入口
| スキル | 向いていること |
|---|---|
| `hyperframes` | 何から始めるか迷ったときの入口。用途に応じて他スキルへ振り分ける |

### 中核
| スキル | 向いていること |
|---|---|
| `hyperframes-core` | プロジェクト構成・コンポジションの正。迷ったらここに従う |
| `hyperframes-animation` | GSAP タイムラインでの動き全般 |
| `hyperframes-keyframes` | キーフレーム単位の細かな動き調整 |
| `hyperframes-creative` | 演出アイデア出し、ルック作り |
| `hyperframes-cli` | `npx hyperframes preview / render` などCLI操作 |
| `media-use` | 画像・音声・動画素材の取り込みと配置 |

### 用途別
| スキル | 向いていること |
|---|---|
| `motion-graphics` | 文字と図形が動くモーショングラフィックス |
| `music-to-video` | 曲のBPM・拍に同期したタイトルやリリック映像 |
| `faceless-explainer` | 顔出しなしの解説動画 |
| `general-video` | 特定ジャンルに当てはまらない汎用の動画 |
| `product-launch-video` | 製品・サービスの発表映像 |
| `embedded-captions` | 字幕の焼き込み |
| `talking-head-recut` | 話者映像の再編集・テロップ付け |
| `pr-to-video` | プルリクエストの内容を紹介動画にする |
| `changelog-video` | 変更履歴・リリースノートの動画化 |
| `figma` | Figma のデザインを素材・レイアウトとして取り込む |

## Remotion 公式

| スキル | 向いていること |
|---|---|
| `/remotion-best-practices` | 入口。Remotion で書くときの原則と各スキルへの案内 |
| `remotion-create` | 新規コンポジションの作成 |
| `remotion-markup` | JSX でのレイアウト・スタイリング |
| `remotion-studio` | Studio でのプレビューと props 調整 |
| `remotion-render` | CLI での書き出し設定 |
| `remotion-captions` | 字幕の生成と表示 |
| `remotion-maps` | 地図を使ったアニメーション |
| `remotion-multimedia` | 音声・動画・画像素材の扱い |

> 正確な一覧はインストール後に `.claude/skills/` を参照してください。
